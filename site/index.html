Five Architectural Ablations

          


          

            
Why Deduplication Matters: Proxy retries replay identical request IDs, creating phantom traffic bursts; 4-level BLAKE2b identity hashing removes exact duplicates without dropping distinct requests.

            
Why Outages Must Not Become Zero: Gaps >900s represent missing telemetry, not zero load. PulseWatch partitions continuous segments and abstains when coverage drops below 40%.

            
Poisson & Negative-Binomial Modeling: Scale-dependent dispersion φ(w) captures natural traffic burstiness; disabling it in Ablation A3 spikes false alarms from 19.2 to 136.8 FP/day.

            
Calibration & Evidence Replay: Rate-stability checks ($Q \ge 20.0$) guard against non-stationary baselines, while bit-packed `RetentionLog` replay guarantees second-pass route attribution matches deduplicated counts byte-for-byte.

          

        

      

    

  


  
  

    

      

        
Developer Setup

        
Run PulseWatch Locally

        
Zero external packages, zero compilation. Verified on Python 3.9.21 through Python 3.14.8.

      


      

        

          bash — clone, test (149 tests), & run 6-scene judge demo
          
        

        
# 1. Clone repository
git clone https://github.com/shreshthss/Pulsewatch.git
cd Pulsewatch

# 2. Run automated test suite (149 tests)
python3 -m unittest discover tests -v

# 3. Execute 5-scenario demo & 6-scene judge demonstration
make demo
python3 scripts/judge_demo.py

# 4. Reproduce 39-scenario benchmark v2 & 5 architectural ablations
python3 -m traffic_lab.benchmark_v2
python3 -m traffic_lab.ablations

      


      

        

          bash — CLI analyze, HTML report, & cryptographic verification
          
        

        
# 1. Analyze JSONL, write canonical report + SHA-256 sidecar manifest
./bin/pulsewatch analyze demo/3_genuine_surge.jsonl --json analysis.json --html report.html

# 2. Independently verify report, manifest, input integrity, & reproduction (11 rules)
./bin/pulsewatch verify analysis.json --input demo/3_genuine_surge.jsonl --reproduce
