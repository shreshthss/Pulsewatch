Engineering Workflow

End-to-End Analysis Pipeline

Every step enforces strict memory bounds, mathematical determinism, and data verification.

01 / LOAD

Stream Ingest

Streams JSONL line-by-line with 8KB line caps and 5M record limit to protect local memory.

02 / VALIDATE

Time Normalization

Normalizes ISO 8601 & Epoch timestamps to nanosecond precision with out-of-order tracking.

03 / DEDUP

BLAKE2b Identity

Deduplicates replayed logs using 16-byte hashes across a 4-level gateway identity hierarchy.

04 / TEMPORAL

Sparse 1s Engine

Partitions time into 1-second sparse bins and isolates unobserved collector gaps (>900s).

05 / DETECT

PW-Scan Engine

Evaluates multi-scale windows (10s, 60s, 300s) using Poisson and Negative-Binomial count modeling.

06 / INVESTIGATE

Evidence & Leads

Trims boundaries to 1s active excess, classifies geometric shape, and assigns concentration tags.

07 / EXPORT

Canonical Report

Exports deterministic JSON (pulsewatch.report/1) and self-contained offline HTML reports.

Technical Capabilities

What Makes PulseWatch Distinct

Engineered to solve real telemetry failure modes that cause false alarms in standard monitoring tools.

⚡

Hierarchical BLAKE2b Deduplication

Enforces a 4-level identity hierarchy (source, seq), (source, trace, span), and (source, request_id). Deduplication only occurs when identities and normalized event attributes match exactly, preserving distinct requests with transparent degradation tracking.

pulsewatch.dedup
⏱️

Sparse 1-Second Temporal Engine

Memory allocation is strictly O(active events) rather than dense arrays proportional to elapsed wall-clock time. Gaps >900s are partitioned into continuous observation segments, ensuring long collector outages never masquerade as zero-traffic.

pulsewatch.temporal
📊

PW-Scan: Multi-Scale Discrete Counts

Models integer arrival counts across 10s, 60s, and 300s timescales. Uses scale-dependent dispersion φ(w) to model overdispersed bursty arrivals via Negative-Binomial parameters, combined with stable log-space tail estimation.

pulsewatch.detector
🛡️

Sticky Contamination Masking

Screens initial candidate windows across fine scales (Z ≥ 4.0), sticky-masks elevated intervals, and refits clean baselines across up to 5 iterations. High baseline contamination triggers explicit reliability downgrades.

Architecture & Math

Statistical Foundations of PW-Scan

Grounding anomaly detection in discrete probability theory and robust estimation.

Adaptive Block Estimation

Selects initial baseline block length L ∈ {60, 300, 900, 3600}s where expected arrivals E ≥ 20. Prevents zero-collapse on sparse low-rate APIs.

  • Median aggregation across clean blocks
  • Guarantees CLT convergence
  • Eliminates integer rounding distortion

Scale-Dependent Dispersion

Models variance-to-mean dispersion ratio φ(w) = Var(S_w) / E(S_w) at each timescale. Detects overdispersion and fits Negative-Binomial parameters (r, q).

  • r = E / (φ - 1), q = E / (r + E)
  • Poisson lower bound when φ ≤ 1.05
  • Prevents over-alerting on bursty callers

Sticky Contamination Masking

Screens initial candidate windows across fine scales (Z ≥ 4.0). Masks elevated intervals and refits clean baseline across up to 5 iterations.

  • Prevents baseline inflation during long surges
  • Tracks fraction of time/events masked
  • Downgrades reliability if >40% masked

Numerically Stable Tail Estimation

Computes upper tail p-values in log-space using stable recurrence relations. Binds omitted tail mass with geometric series convergence checks.

  • Exact convergence error bounds
  • Emits tail_exact boolean flag
  • Zero float overflow or underflow
Developer Setup

Run PulseWatch Locally

Zero external packages, zero compilation. Runs anywhere with standard Python 3.9+.

bash — clone & run demo suite 
# 1. Clone repository
git clone https://github.com/shreshthss/Pulsewatch.git
cd Pulsewatch

# 2. Run automated test suite (29 tests in ~0.25s)
make test

# 3. Execute 5-scenario curated demonstration suite
make demo

# 4. Run comprehensive 13-scenario benchmark matrix
make matrix
bash — standard CLI workflow 
# 1. Summarize deduplicated traffic windows
./bin/pulsewatch summarize data/sample.jsonl

# 2. Detect anomalies and output canonical JSON report
./bin/pulsewatch analyze data/sample.jsonl --json data/analysis.json

# 3. Render self-contained standalone HTML report
./bin/pulsewatch report data/analysis.json --html data/report.html
